## 💫 About Me

> *"I don't just write code — I build systems that think."*

Hey there! I'm **Sujal Koshta**, a passionate **Full-Stack Developer** and **Machine Learning Engineer** from India 🇮🇳. I sit at the exciting intersection of scalable web engineering and intelligent AI systems — building production-grade applications that don't just work, but *learn*.

- 🧠 I obsess over **deep learning architectures** — from CNNs to RNNs — and love tracing the mathematical elegance beneath them
- 🌐 On the web side, I craft end-to-end products with **React, Next.js, FastAPI, and Node.js**, putting equal care into performance and user experience
- 🔁 I have a knack for **bridging the gap** between ML research and real-world deployment — taking models from Jupyter notebooks to live APIs
- 📐 I believe great software is built on clarity: clear architecture, clean code, and clear thinking

---

## 🔭 What I'm Building

Right now, I'm deep in the trenches of:

- **Full-stack web applications** with role-based dashboards, real-time features, and scalable REST/FastAPI backends (see [centerofexcellence](https://github.com/sujaldef/centerofexcellence))
- **AI-powered platforms** like [Skillnavigator](https://github.com/sujaldef/Skillnavigator) — an adaptive learning system spanning 250+ job roles using intelligent assessments and dynamic content
- **ML project collections** — hands-on experiments applying core machine learning concepts to real-world datasets
- **Deep learning models** — experimenting with neural network architectures for classification, prediction, and generative tasks
